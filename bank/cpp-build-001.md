# 题目

gcc 编译一个 C++ 源文件时，完整的编译过程依次经过哪四个阶段？

A. 词法分析 → 语法分析 → 语义分析 → 代码生成
B. 预处理 → 编译 → 汇编 → 链接
C. 编译 → 预处理 → 汇编 → 链接
D. 编译 → 汇编 → 链接 → 预处理

## 选项解析

- A：这是编译器内部的逻辑阶段，不是 gcc 对外暴露的四阶段划分。
- B：正确。预处理（.i）→ 编译（.s）→ 汇编（.o）→ 链接（可执行文件）。
- C：预处理必须在编译之前。
- D：顺序完全错误。
