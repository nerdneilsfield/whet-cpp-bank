# 程序的虚拟地址空间布局（Linux 进程内存映射）

## 参考答案

### 64-bit Linux 进程虚拟地址空间（概览）

```
虚拟地址（高→低）
0xFFFFFFFFFFFFFFFF
  ┌─────────────────────────┐
  │  内核空间（不可直接访问）   │ 128 TB（高半部分）
  │  系统调用、内核数据结构    │
  ├─────────────────────────┤  ← 用户空间上边界 ~0x7FFFFFFFFFFF
  │  栈（Stack）              │ 默认 8 MB，ulimit -s 控制
  │  ↓ 向低地址增长            │ 存：局部变量、函数帧、返回地址
  │  ~~~~ (随机 gap，ASLR) ~~~~│
  ├─────────────────────────┤
  │  mmap 区域               │ 共享库（.so）、文件映射
  │  ↓ 向低地址增长（通常）    │ mmap()/mmap2() 分配的匿名大块
  │  ~~~~ (随机 gap，ASLR) ~~~~│
  ├─────────────────────────┤
  │  堆（Heap）               │ malloc/new，sbrk() 扩展
  │  ↑ 向高地址增长            │
  ├─────────────────────────┤  ← program break (brk)
  │  BSS 段                  │ 未初始化全局/静态变量（零填充）
  ├─────────────────────────┤
  │  .data 段                │ 已初始化全局/静态变量
  ├─────────────────────────┤
  │  .rodata 段              │ 字符串字面量、const 全局
  ├─────────────────────────┤
  │  .text 段（代码区）        │ 机器指令，只读可执行
  ├─────────────────────────┤
  │  保留区 / NULL 页         │ 0x0–0x10000，捕获空指针解引用
  └─────────────────────────┘
0x0000000000000000
```

### 各区域详解

| 区域 | 权限 | 内容 | 增长方向 |
|------|------|------|---------|
| 内核空间 | 不可访问 | 内核代码/数据/页表 | — |
| 栈 | rw | 局部变量、帧指针、返回地址 | 向低地址 ↓ |
| mmap | rw/rx | 共享库、文件映射、大匿名块 | 向低地址 ↓ |
| 堆 | rw | `new`/`malloc` 分配的对象 | 向高地址 ↑ |
| BSS | rw | 未初始化全局/静态（OS 零初始化） | — |
| .data | rw | 已初始化全局/静态 | — |
| .rodata | r | 字符串字面量、const 全局 | — |
| .text | rx | 程序指令 | — |

### mmap 区域的重要性

- **共享库加载**：`libc.so`、`libstdc++.so` 等通过 `mmap` 映射，多进程共享物理页（只读代码段只需一份）。
- **大块分配**：glibc `malloc` 对 > 128 KB 的请求直接用 `mmap`（而非 `sbrk`），释放时直接 `munmap`，不会造成 heap 碎片。
- **文件映射**：`mmap(fd, ...)` 将文件内容映射到地址空间，读写文件如读写内存，避免 read/write 系统调用的数据拷贝。

### ASLR（地址空间布局随机化）

Linux 默认开启 ASLR（`/proc/sys/kernel/randomize_va_space = 2`）：栈基址、mmap 区域基址、堆起始地址每次启动随机偏移，防止 ROP/堆喷等攻击。可通过 `setarch -R ./myapp` 临时禁用（调试用）。

### 查看实际映射

```bash
# 查看当前进程内存映射
cat /proc/self/maps

# 示例输出（字段：起始-结束地址 权限 偏移 设备 inode 路径名）
# 55a3b1200000-55a3b1201000 r-xp 00000000 fd:01 1234 /usr/bin/myapp  (.text)
# 55a3b1401000-55a3b1402000 rw-p 00001000 fd:01 1234 /usr/bin/myapp  (.data)
# 7f8a00000000-7f8a00021000 rw-p 00000000 00:00 0                     (堆/匿名)
# 7ffdb2345000-7ffdb2366000 rw-p 00000000 00:00 0 [stack]
```

```cpp
// 程序内读取自身映射
#include <cstdio>
int main() {
    FILE* f = fopen("/proc/self/maps", "r");
    char line[256];
    while (fgets(line, sizeof(line), f)) fputs(line, stdout);
    fclose(f);
}
```
