# 整数除以零

关于整数除以零（`int x = 5 / 0`），下列说法正确的是？

A. C++ 标准规定必须抛出异常
B. 属于编译错误，编译器会拒绝编译
C. 结果为 0，和大多数语言一样
D. 属于未定义行为，标准不规定任何结果

## Explanation

正确答案是 D，即 属于未定义行为，标准不规定任何结果。它符合题目代码/概念对应的 C++ 语言规则或标准库语义，而 A、B、C 通常来自下标、类型、生命周期、复杂度或平台保证的混淆。未定义行为题的关键是区分“标准无保证”和“某次运行看起来正常”；一旦触发 UB，编译器可基于其不会发生来优化。 做这类题时应先判断标准层面的语义，再考虑题目是否给出了特定平台假设。
