# C++ 内存分区各存什么？

## 参考答案

C++ 程序运行时，进程内存分为以下几个区域：

### 1. 代码区（Text Segment）

存放**编译后的机器指令**（函数体代码）。只读，防止程序意外修改自身指令。通常与常量区合并，字符串字面量也放这里（只读数据段 `.rodata`）。

```cpp
const char* s = "hello";  // "hello" 存于只读数据区
```

### 2. 全局/静态数据区（Data Segment，已初始化）

存放**已初始化的全局变量和静态局部变量**。程序启动时即存在，程序结束时销毁。

```cpp
int g_val = 42;           // .data 段
static int s_val = 10;    // .data 段
```

### 3. BSS 段（Block Started by Symbol，未初始化）

存放**未初始化或零初始化的全局/静态变量**。可执行文件中 BSS 不占磁盘空间（仅记录大小），OS 加载时用零填充。

```cpp
int g_uninit;             // BSS 段，自动零初始化
static int s_zero = 0;    // 优化后通常也入 BSS
```

### 4. 栈区（Stack）

存放**局部变量、函数参数、返回地址、寄存器保存值**。由编译器自动管理，LIFO 结构，分配极快（移动栈指针即可）。默认大小一般 1–8 MB，溢出导致 stack overflow。

```cpp
void foo() {
    int local = 5;     // 栈上分配
    int arr[1024];     // 栈上分配
}  // 函数返回时自动释放
```

### 5. 堆区（Heap）

存放 `new`/`malloc` **动态分配的内存**。由程序员手动管理（或智能指针），生命周期跨越函数调用。分配比栈慢（涉及内存管理算法），可能产生碎片。

```cpp
int* p = new int[100];   // 堆上分配
delete[] p;              // 手动释放
```

### 内存分布示意（Linux 64-bit，低地址→高地址）

```
低地址
  ┌──────────────┐
  │  代码区 .text │
  ├──────────────┤
  │  .rodata     │  字符串字面量、const 全局
  ├──────────────┤
  │  .data       │  已初始化全局/静态
  ├──────────────┤
  │  .bss        │  未初始化全局/静态（零初始化）
  ├──────────────┤
  │  堆 ↑        │  new/malloc，向高地址增长
  │  ...         │
  │  栈 ↓        │  局部变量，向低地址增长
  ├──────────────┤
  │  内核空间    │
高地址
```

> **易混淆点**：常量局部变量（`const int x = 5;`）仍在栈上；字符串字面量在只读数据区；`static` 局部变量不在栈上，在 .data/.bss。
