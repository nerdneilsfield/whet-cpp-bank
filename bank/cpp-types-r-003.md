# 代码阅读：列表初始化窄化转换

以下代码能否编译通过？

```cpp
double d = 3.14;
int x{d};
```

A. 编译成功，`x == 3`（隐式截断）  
B. 编译错误（或强制诊断）：列表初始化不允许窄化转换  
C. 编译成功，`x == 3.14`（double 存入 int）  
D. 运行时抛出异常

## 解析

正确答案是 B，即 编译错误（或强制诊断）：列表初始化不允许窄化转换。它符合题目代码/概念对应的 C++ 语言规则或标准库语义，而 A、C、D 通常来自下标、类型、生命周期、复杂度或平台保证的混淆。类型题要关注值类别、cv 限定、隐式转换和推导规则；常见错误是忽略顶层/底层 const 或数组/函数退化。 做这类题时应先判断标准层面的语义，再考虑题目是否给出了特定平台假设。
