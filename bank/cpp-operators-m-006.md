关于 C++ 中 `%`（取模）运算符，下列哪些说法正确？选择所有正确项。

A. `%` 只能用于整数类型操作数，不能直接用于 `float` 或 `double`。
B. `-7 % 3` 的结果在 C++11 及以后标准中是 `2`。
C. `-7 % 3` 的结果在 C++11 及以后标准中是 `-1`（结果符号与被除数一致）。
D. `7 % 0` 是合法操作，结果为 `0`。

## Explanation

正确答案是 A, C。A 项 ``%` 只能用于整数类型操作数，不能直接用于 `float` 或 `double`。` 符合规则；C 项 ``-7 % 3` 的结果在 C++11 及以后标准中是 `-1`（结果符号与被除数一致）。` 符合规则；B 项 ``-7 % 3` 的结果在 C++11 及以后标准中是 `2`。` 不满足该规则；D 项 ``7 % 0` 是合法操作，结果为 `0`。` 不满足该规则。运算符题的关键是先按 C++ 的优先级、结合性和求值规则拆表达式，再判断每一步的值。常见误区是把按位运算和逻辑运算混淆，或误以为所有二元运算都会短路求值。 多选题常见误区是只看关键字相似就勾选，而没有逐项检查它是否真的满足题干条件。
