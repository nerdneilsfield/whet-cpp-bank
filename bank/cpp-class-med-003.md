下列代码哪一行会编译失败？

```cpp
struct S {
    explicit S(int)         {}
    explicit S(int, int)    {}
};

void f(S);

S s1 = 1;          // (1)
S s2(2);           // (2)
S s3{3, 4};        // (3)
f({5});            // (4)
```

A. (1) 和 (2)
B. (1) 和 (4)
C. (3) 和 (4)
D. 全部合法

---

**解析：**

`explicit` 禁止**隐式转换序列**与**拷贝初始化**形式调用该构造函数。

- (1) `S s1 = 1;` 属于拷贝初始化，需要隐式地由 `int` 转到 `S`，被 `explicit` 拒绝。
- (2) `S s2(2);` 是直接初始化，允许显式调用 `explicit` 构造函数。
- (3) `S s3{3, 4};` 直接列表初始化同样属于直接初始化范畴，允许。
- (4) `f({5})` 形参类型是 `S`，`{5}` 要做拷贝列表初始化到 `S`，C++17 起这仍被 `explicit` 拒绝。

因此 (1) 和 (4) 编译失败。C++20 引入 `explicit(bool)` 可按条件启用该限制。

## 解析

正确答案为 B，因为“(1) 和 (4)”符合题干所问的 C++ 规则或代码执行结果。A、C、D 项分别混淆了相近概念、错误语法或不会发生的执行路径。常见误区是凭直觉看关键字，而没有按标准规则和代码顺序逐步判断。类与对象题要区分默认访问权限、对象生命周期、静态成员、const 成员函数和初始化规则。
