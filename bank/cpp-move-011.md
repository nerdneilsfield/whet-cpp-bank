# 代码阅读：拷贝还是移动？

以下代码调用的是拷贝构造函数还是移动构造函数？

```cpp
std::vector<int> v1 = {1, 2, 3};
std::vector<int> v2 = v1;
```

A. 移动构造函数，因为 v1 在之后不再使用
B. 拷贝构造函数，因为 v1 是具名 lvalue
C. 移动构造函数，因为赋值号右边是 v1
D. 编译器自动选择，结果不确定

## Explanation

正确答案是 B，`v1` 是具名变量，表达式 `v1` 是左值，所以用它初始化 `v2` 会调用拷贝构造。编译器不会因为程序员之后不再使用 `v1` 就自动把它当右值移动。若想允许移动，必须写 `std::move(v1)` 或传入真正的右值。 这类题的关键是区分语法形式、对象生命周期和所有权语义：语法看似相近时，应先判断谁拥有资源、表达式值类别是什么，以及标准是否保证该行为；不要根据实现习惯或表面写法推断答案。
