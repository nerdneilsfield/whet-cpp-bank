若 A 是 B 的友元，B 是 C 的友元，则下列说法正确的是？

A. A 也是 C 的友元（友元可以传递）
B. A 不是 C 的友元（友元不可传递）
C. C 也是 A 的友元（友元是双向的）
D. A、B、C 互为友元

## 解析

正确答案是 B，对应“A 不是 C 的友元（友元不可传递）”。本题考查友元声明的访问权限规则，关键是友元只授予特定函数或类访问权，不会自动成为成员。其他选项容易混淆相关概念：A 项“A 也是 C 的友元（友元可以传递）”不满足题干要求；C 项“C 也是 A 的友元（友元是双向的）”不满足题干要求；D 项“A、B、C 互为友元”不满足题干要求。常见误区是只凭关键字判断，而没有结合完整声明、表达式求值结果或 C++ 语义限制。
