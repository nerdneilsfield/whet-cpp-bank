关于下列位域结构体，哪一项描述**错误**？

```cpp
struct Packed {
    unsigned a : 3;
    unsigned b : 5;
    unsigned c : 8;
};
Packed p{};
```

A. `Packed` 的对象表示中，`a` 通常和 `b`、`c` 共享同一个存储单元，整体可能只占 4 字节
B. 写入 `p.a = 9;` 时高位被截断为低 3 位，结果是 1
C. 同一存储单元内相邻位域的相对排列顺序（高位优先还是低位优先）是实现定义
D. `&p.a` 合法，返回类型为 `unsigned*`，可用于做指针运算

---

**解析：**

D 是错误的：标准 [class.bit]/3 明确**位域不是可寻址的对象**，对其使用一元 `&` 是 ill-formed，因为位域不一定按字节对齐。要取地址必须先取整个结构体地址，再做位运算。

其它选项均正确：

- A：连续的位域只要类型相同且总位数不超过存储单元宽度，编译器会把它们打包到同一个 `unsigned` 里；`3+5+8=16` 位通常占 4 字节（含尾部对齐填充）。
- B：把 9（二进制 1001）写入 3 位位域，标准对无符号位域规定按 2^N 取模，结果为 `001 = 1`。
- C：位域在存储单元内的物理排布顺序由实现定义，跨编译器/ABI 不可移植，这正是位域不应用于网络协议二进制布局的原因。

## Explanation

正确答案为 D，因为“`&p.a` 合法，返回类型为 `unsigned*`，可用于做指针运算”符合题干所问的 C++ 规则或代码执行结果。A、B、C 项分别混淆了相近概念、错误语法或不会发生的执行路径。常见误区是凭直觉看关键字，而没有按标准规则和代码顺序逐步判断。类与对象题要区分默认访问权限、对象生命周期、静态成员、const 成员函数和初始化规则。
