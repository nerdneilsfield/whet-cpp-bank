# 代码阅读：整数字面量溢出

以下代码的行为是什么？

```cpp
#include <iostream>
int main() {
    int x = 2147483648;
    std::cout << x << "\n";
}
```

A. 输出 `2147483648`  
B. 编译错误：字面量超出 `int` 范围  
C. 编译警告（溢出），输出 `-2147483648`（实现定义/UB，典型结果）  
D. 编译成功，输出 `0`

## Explanation

正确答案是 C，即 编译警告（溢出），输出 `-2147483648`（实现定义/UB，典型结果）。它符合题目代码/概念对应的 C++ 语言规则或标准库语义，而 A、B、D 通常来自下标、类型、生命周期、复杂度或平台保证的混淆。类型题要关注值类别、cv 限定、隐式转换和推导规则；常见错误是忽略顶层/底层 const 或数组/函数退化。 做这类题时应先判断标准层面的语义，再考虑题目是否给出了特定平台假设。
