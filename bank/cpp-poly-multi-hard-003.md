关于纯虚函数（pure virtual function），以下说法正确的是哪些？

```cpp
struct Base {
    virtual void f() = 0;
    virtual ~Base() = 0;     // 纯虚析构
};
void Base::f() { /* 可以有实现 */ }
Base::~Base() { /* 必须有实现 */ }
```

A. 纯虚函数可以有函数定义（实现）；派生类可通过 `Base::f()` 显式调用基类的实现。
B. 纯虚析构函数**必须**提供实现，否则派生类析构时会链接错误——因为派生类析构函数总会隐式调用基类析构函数。
C. 任何包含纯虚函数的类都不能在派生类中实例化（即派生类一旦覆盖纯虚函数仍是抽象类）。
D. 在构造函数或析构函数中通过虚分派调用纯虚函数会导致未定义行为（通常运行时报 "pure virtual function called"）。

---

**解析：**

A 正确：`= 0` 仅声明它"必须被覆盖"，并不禁止提供函数体；派生类可通过 `Base::f()` 限定调用获得基类的默认实现，是常见的设计技巧（如提供部分默认行为）。
B 正确：派生类析构函数会按继承层级链式调用基类析构，所以纯虚析构必须提供函数体定义，否则链接器找不到符号；这是 C++ 中纯虚析构的特殊要求。
C 错误：派生类只要覆盖了所有纯虚函数就不再是抽象类，可以实例化。"任何包含纯虚函数的类"指的是基类自身不可实例化，但派生覆盖后即可。
D 正确：构造/析构期间动态类型不是派生类，若通过虚分派调用未在 `Base` 中实现的纯虚函数，会跳转到 `__cxa_pure_virtual` 钩子，运行时打印诊断并 abort。
