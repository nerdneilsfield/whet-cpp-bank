# 认知：enum class 作用域

下列关于 `enum class` 的说法，**正确**的是？

A. `enum class` 中的枚举值会隐式转换为 `int`
B. `enum class Color { Red };` 后可以直接写 `int x = Red;`
C. `enum class` 的枚举值必须通过作用域限定符访问，如 `Color::Red`
D. `enum class` 与普通 `enum` 的作用域规则完全相同
