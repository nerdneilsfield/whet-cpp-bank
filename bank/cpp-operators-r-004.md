# 代码阅读：复合赋值的返回值

```cpp
#include <iostream>
int main() {
    int x = 3;
    int y = (x += 4);
    std::cout << x << " " << y << "\n";
}
```

输出是什么？

A. `3 7`  
B. `7 7`（复合赋值返回左值，即赋值后的 `x`）  
C. `7 3`  
D. `4 7`

## 解析

正确答案是 B，因为该选项对应 ``7 7`（复合赋值返回左值，即赋值后的 `x`）`，符合题中代码或概念的 C++ 语义。运算符题的关键是先按 C++ 的优先级、结合性和求值规则拆表达式，再判断每一步的值。常见误区是把按位运算和逻辑运算混淆，或误以为所有二元运算都会短路求值。 A 项、C 项、D 项 的问题在于忽略了上述规则中的一个关键条件，因此会得到看似合理但错误的结论。
