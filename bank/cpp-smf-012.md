以下代码中，`f2 = f1;` 调用的是哪个特殊成员函数？

```cpp
struct Foo { int x; };
Foo f1{42};
Foo f2{0};
f2 = f1;
```

A. 默认构造函数
B. 拷贝构造函数
C. 拷贝赋值运算符
D. 移动赋值运算符

## 解析

正确答案是 C，`f2` 已经通过 `Foo f2{0};` 构造完成，之后的 `f2 = f1;` 是对已有对象赋新值。右侧 `f1` 是左值，因此调用拷贝赋值运算符。若右侧写成 `std::move(f1)`，才可能选择移动赋值。 这类题的关键是区分语法形式、对象生命周期和所有权语义：语法看似相近时，应先判断谁拥有资源、表达式值类别是什么，以及标准是否保证该行为；不要根据实现习惯或表面写法推断答案。
