# 数组越界写入

```cpp
int arr[3] = {1, 2, 3};
arr[3] = 99;   // 下标 3，数组大小为 3
```

上述代码的行为是：

A. 未定义行为，可能损坏相邻内存
B. 编译错误，越界访问在编译期检测
C. 运行时必然抛出异常
D. 合法：C++ 数组允许写入"结束哨兵"位置

## 解析

正确答案是 A，即 未定义行为，可能损坏相邻内存。它符合题目代码/概念对应的 C++ 语言规则或标准库语义，而 B、C、D 通常来自下标、类型、生命周期、复杂度或平台保证的混淆。未定义行为题的关键是区分“标准无保证”和“某次运行看起来正常”；一旦触发 UB，编译器可基于其不会发生来优化。 做这类题时应先判断标准层面的语义，再考虑题目是否给出了特定平台假设。
