关于引用折叠（reference collapsing）规则，以下说法正确的是哪些？

```cpp
using L = int&;
using R = int&&;

L&  a;   // (1)
L&& b;   // (2)
R&  c;   // (3)
R&& d;   // (4)
```

A. (1) `L&` → `int& &` → `int&`：左值引用的左值引用折叠为左值引用。
B. (2) `L&&` → `int& &&` → `int&`：左值引用的右值引用折叠为左值引用。
C. (3) `R&` → `int&& &` → `int&`：右值引用的左值引用折叠为左值引用。
D. (4) `R&&` → `int&& &&` → `int&&`：右值引用的右值引用折叠也是左值引用。

---

**解析：**

A 正确：`T& &` → `T&`，两条规则中"只要有一个是左值引用"最终就是左值引用，两个左值引用当然也是左值引用。
B 正确：`T& &&` → `T&`，左值引用的右值引用折叠为左值引用，这是引用折叠中最重要的应用——forward 机制的基础。
C 正确：`T&& &` → `T&`，同样遵循"任何 & 参与折叠结果就是 &"的规则。
D 错误：`T&& &&` → `T&&`，只有纯右值引用折叠（两个 &&）才保持右值引用，不是左值引用。引用折叠规则总结为：`& & → &`、`& && → &`、`&& & → &`、`&& && → &&`。记忆口诀："只要出现 `&`，结果就是 `&`"。
