关于**匿名命名空间**（`namespace { ... }`），下列哪些说法**正确**？（选择所有正确项）

A. 匿名命名空间中的符号具有外部链接，可被其他翻译单元访问
B. 匿名命名空间中的符号具有内部链接，等效于 C 语言中的 `static` 文件作用域
C. 每个翻译单元的匿名命名空间彼此独立，同名符号不会冲突
D. 匿名命名空间可用于替代 `static` 关键字来限制符号的可见性范围

## 解析

正确答案是 B, C, D。B 项 `匿名命名空间中的符号具有内部链接，等效于 C 语言中的 `static` 文件作用域` 符合规则；C 项 `每个翻译单元的匿名命名空间彼此独立，同名符号不会冲突` 符合规则；D 项 `匿名命名空间可用于替代 `static` 关键字来限制符号的可见性范围` 符合规则；A 项 `匿名命名空间中的符号具有外部链接，可被其他翻译单元访问` 不满足该规则。预处理题要记住宏在编译前做文本替换，条件编译和 include guard 也都发生在语义分析之前。常见误区是把宏当成有类型的函数，或忽略宏参数重复求值和括号不足带来的副作用。 多选题常见误区是只看关键字相似就勾选，而没有逐项检查它是否真的满足题干条件。
