# 代码阅读：负数整数除法截断方向

```cpp
#include <iostream>
int main() {
    std::cout << -7 / 2 << "\n";
}
```

C++11 及以后标准规定整数除法向零截断，输出是什么？

A. `-4`（向负无穷截断）  
B. `3`  
C. `-3`（向零截断，`-7/2 = -3.5` → `-3`）  
D. 未定义行为

## 解析

正确答案是 C，因为该选项对应 ``-3`（向零截断，`-7/2 = -3.5` → `-3`）`，符合题中代码或概念的 C++ 语义。运算符题的关键是先按 C++ 的优先级、结合性和求值规则拆表达式，再判断每一步的值。常见误区是把按位运算和逻辑运算混淆，或误以为所有二元运算都会短路求值。 A 项、B 项、D 项 的问题在于忽略了上述规则中的一个关键条件，因此会得到看似合理但错误的结论。
